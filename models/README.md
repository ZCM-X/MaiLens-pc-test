# PC detector models

`frame-geometry-yolo11n-v4.onnx` is the current geometry detector. It exposes
`outer_buttons` (the cabinet ring around the screen and buttons) and
`inner_screen`; the machine lock uses both, and `inner_screen` is the class the
lock depends on most.

| model | training data | note |
| --- | --- | --- |
| `frame-geometry-yolo11n-v2.onnx` | 51 hand-labelled photos | inner_screen only reached 0.2-0.4 confidence on real phone footage |
| `frame-geometry-yolo11n-v3.onnx` | early 5-image experiment | kept for comparison only |
| `frame-geometry-yolo11n-v4.onnx` | 354 images | current default; mAP50 0.97 on the manual split |

v4 mixes the 51 hand labels with 97 photos from `D:\桌面文件\训练2` and 211
raw-fisheye frames sampled from the captured sessions:

```powershell
.\.venv\Scripts\python.exe tools\build_geometry_dataset.py `
  --source-dataset datasets\maimoller-geometry --source-sessions sessions `
  --photo-dir "D:\桌面文件\训练2" `
  --model models\frame-geometry-yolo11n-v2.onnx `
  --output datasets\maimoller-geometry-v3 --samples-per-session 12 --max-side 1600

.\.venv\Scripts\python.exe tools\train_detector.py `
  --dataset datasets\maimoller-geometry-v3\dataset.yaml `
  --weights ..\..\yolo11n.pt --device 0 --epochs 100 --imgsz 640 --batch 16 `
  --project runs --name geometry-v3 --export onnx
```

Labels for the extra images are generated by the current model plus the median
inner/outer margins learned from the hand-labelled set, so more real material
with correct hand labels is always the best next step.

## On-device model

`Training/export_coreml.py` converts `Training/machine-detector.pt` (the v4
weights) into `iOS/Resources/MachineDetector.mlpackage` during the macOS build.
The pipeline takes `image` plus `iouThreshold`/`confidenceThreshold` and returns
`confidence` (boxes x classes) and `coordinates` (boxes x normalized
`x, y, width, height`).

A separate gameplay model may expose `button`/`inner_screen` or
`slide`/`inner_screen`; its detections are intentionally not used by the
cabinet lock.
